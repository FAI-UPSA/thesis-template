# Third-Party Notices

## Typefaces and Fonts

This repository bundles third-party fonts under the `assets/fonts` directory solely to ensure consistent and reliable document compilation with Typst.

The primary license governing this repository does not apply to the bundled fonts. All fonts are distributed strictly under their respective upstream licenses.

For licensing and copyright information, please refer to the license and notice files located in each font family's directory under `assets/fonts/`.

Font files are retained without modification. Distributions may be pruned to omit webfonts and operating-system metadata while preserving desktop fonts and upstream documentation and licenses.

The upstream license, including its disclaimer of warranties, is preserved in `assets/fonts/Reforma/LICENSE.txt`; the upstream documentation is preserved in `README.txt` and `LEEME.txt` in the same directory.

This repository retains the unmodified desktop OpenType fonts for Reforma 1918, Reforma 1969, and Reforma 2018, along with the Spanish and English instructions and specimen PDFs. Webfonts and macOS `.DS_Store` metadata are omitted.

The upstream instructions (page 2) ask users to credit the authors when using Reforma and not to modify the typeface design. They provide this short credit for documents: “Reforma, PampaType / Universidad Nacional de Córdoba [AR]”. Include this credit in documents using Reforma, for example in the acknowledgements or production credits.
